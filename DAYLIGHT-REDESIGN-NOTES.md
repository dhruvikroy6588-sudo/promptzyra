# Promptzyra Daylight UI Redesign

This update keeps the existing Promptzyra identity and changes the public-facing UI back to a polished daylight theme.

## Visual system preserved
- White / soft lavender surfaces
- Existing violet brand accent (#7155F5)
- Mint and lime as supporting accent colors
- Dark charcoal typography
- Existing image cards, prompt/blog routes, Supabase data flow, admin components, R2 upload route, GA4 tag, and Search Console verification file are preserved.

## UI changes
- Public header navigation now highlights Prompt Library, Categories, Creator Guides, and AI Image Tool.
- Homepage, cards, category tiles, festival feature, newsletter and footer use a consistent light palette.
- Better surface contrast, subtle borders/shadows, and responsive navigation spacing.
- Footer/tool wording is generalized from Gemini Image Tool to AI Image Tool.

## Deployment
Run the existing project build/deploy workflow. This source update has not been production-build tested in this environment because dependencies are not installed here.
