# AI tools ko 5,000+ tak kaise badhayein (sahi tareeka)
- Admin -> Import Drafts -> AI tools: CSV/JSON se hazaaron rows draft me import hoti hain (40-40 ke batch me).
- Minimum columns: name, category, website_url, pricing, tagline. Baaki fields baad me enrich karein.
- Sirf wahi tool publish karein jinki official site, pricing type aur description aapne verify ki ho.
- /ai-tools/submit se tool-makers khud submit karte hain; Admin -> Submissions me review karke "Create draft tool".
- Doosri sites ka data copy na karein (copyright + AdSense thin-content risk).
