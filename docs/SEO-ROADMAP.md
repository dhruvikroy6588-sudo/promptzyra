# Promptzyra SEO roadmap (education + prompts + tools + resume)

## Positioning
"Learn AI with tested prompts, honest tool guides and a free resume builder." Audience: students, teachers, job seekers.

## What is already built in
- Server-rendered pages (Google sees full HTML), canonical URLs, unique titles/descriptions, Open Graph, JSON-LD (Organization, WebSite+SearchAction, BreadcrumbList, Article, FAQPage, SoftwareApplication, CreativeWork, ItemList).
- Auto sitemap (`/sitemap.xml`) with all live prompts, tools, posts, categories. `robots.txt` blocks admin, API, search, editor.
- Filter/search/page-2+ URLs are `noindex` to avoid thin duplicate pages. Resume editor is `noindex`.
- Trust pages for AdSense: About, Contact, Privacy, Terms, Disclaimer, Editorial policy, Advertising disclosure. Cookie consent. `/ads.txt` from Admin → Settings.

## Phase 0 — Before applying to AdSense (weeks 1–4)
1. Run the SQL, import drafts, **rewrite and enrich** each item you publish (add your own examples, tips, screenshots).
2. Go live with **100–150 reviewed prompts**, 40+ tool guides (150–250 original words each), 10+ blog articles.
3. Do not publish the old 200 starter cards as they are (templated text and hot-linked images). Keep them draft or rewrite.
4. Add real author name/bio on About, a working contact email, and check every legal page.
5. Submit sitemap in Search Console; check Coverage weekly.

## Phase 1 — Weeks 5–12: publish steadily
- 5 prompts/day is the maximum; 2–3/day with real edits is better. Add 2 blog posts/week.
- Fill every category (min 8 items) so category pages are useful, and write the category intro in Admin → Categories.
- Link between types: each prompt → related tools; each tool → prompts; blog → both. (Use `related_tools` and `alternatives`.)

## Phase 2 — Month 3+: topical depth
Target clusters (examples):
- Students: study plan prompts, flashcards, exam revision, essay feedback.
- Teachers: lesson plans, quizzes, rubrics, differentiation.
- Careers: resume bullets by job (nurse, analyst, teacher), cover letters, interview questions, ATS.
- Tools: "best AI tools for students / teachers / note-taking / presentations", honest comparisons ("X vs Y").
- Resume pages: `/resume-templates/<category>` already exist; add guides per profession ("software engineer resume example").

## Content rules that protect rankings and AdSense
- Each page must teach something the reader cannot get by copy-paste alone: when to use, steps, example output, mistakes.
- No fake reviews, no invented pricing, no copied text. Show "last reviewed" on tools; leave pricing as a type.
- Fix or delete pages that get no impressions after 90 days.

## Measure
Search Console: impressions, clicks, pages indexed, queries. Analytics: engaged sessions, copy events. Review monthly and double down on categories that grow.

## Honest expectations
New sites typically need 3–6 months to rank. AdSense approval depends on content quality, originality and policy compliance; no one can guarantee it. Apply when the site has real depth, not before.
