## Poster prompt library references

Promptzyra includes an original 100-entry poster prompt collection and original illustrative SVG layout previews in `data/poster-prompts.json` and `public/poster-previews/`. These were authored for this project and are not copies of third-party image assets.

The poster library links to the following external resources for further exploration. No third-party preview images or community prompt text are bundled from these sources in this release:

- The Art Director — https://github.com/sijingsun/the-art-director (MIT repository; check individual assets).
- AI Visual Prompt Cookbook — https://github.com/zyt-ngchwanlii/ai-visual-prompt-cookbook (individual style files may be CC BY 4.0; attribution is required for reuse).
- Pixmind GPT Image prompts — https://github.com/Pixmind-io/awesome-gpt-image-2-prompts (upstream terms should be checked before republishing content).
- YouArt community GPT Image prompts — https://github.com/youart-open-source/awesome-gpt-image-2-5-prompts (retain original authorship and source terms; linked, not copied).
- No-Chili prompt archive — https://github.com/no-chili/awesome-gpt-image-2-prompts (verify license and individual image rights before reuse).
- Poster101K dataset — https://github.com/Poster101K (research dataset; verify commercial redistribution rights per asset).

- Poster101K research dataset — https://github.com/AnonymousDog10/Poster101K (CC BY-NC-ND 4.0; research/non-commercial restrictions; linked only).
- PosterCraft Poster100K — https://huggingface.co/datasets/PosterCraft/Poster100K (CC BY-NC-SA 4.0; linked only, not bundled).
- GenPoster100K — https://huggingface.co/datasets/creative-graphic-design/GenPoster100K (CC BY-NC 4.0; linked only, not bundled).
